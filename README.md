## 📂 Projects Overview

### 1️⃣ Domino’s Pizza Sales Analysis (SQL Server)
📁 Folder: `Dominos_sql_project`

#### 📌 Project Overview
This project analyzes Domino’s pizza sales data to uncover insights related to **customer behavior, order trends, revenue performance, and operational efficiency** using SQL Server.

#### 📊 Dataset
- Customers  
- Orders  
- Order Details  
- Pizzas  
- Pizza Types  

(Data sourced from a pizza sales dataset)

#### 🗂 Database Structure
Tables used:
- `customers` – Customer details  
- `orders` – Order-level information (date, time)  
- `order_details` – Order item details and quantities  
- `pizzas` – Pizza size and pricing  
- `pizza_types` – Pizza category and names  

#### 🔍 Key Analysis Performed
- Customer segmentation (repeat vs one-time customers)
- Peak ordering hours and time-based trends
- Top-selling pizzas and categories
- Revenue analysis (daily, monthly, cumulative)
- Average order size and operational metrics

#### 📈 Key Insights
- Identified peak order hours to support staffing optimization
- Found top revenue-contributing pizzas and categories
- Analyzed repeat customer contribution to total revenue
- Discovered ordering patterns by time and date

### 2️⃣ Netflix Movies & TV Shows Analysis (SQL Server)
📁 Folder: `Netflix_SQL_Project`

#### 📌 Project Overview
This project performs an in-depth SQL analysis of Netflix’s movies and TV shows dataset to extract insights about **content distribution, ratings, countries, release trends, and categorization**.

#### 📊 Dataset
- Netflix titles dataset sourced from Kaggle

#### 🔍 Key Analysis Performed
- Distribution of Movies vs TV Shows
- Most common content ratings
- Content trends by release year
- Country-wise content analysis (with focus on India)
- Duration and genre-based insights
- Keyword-based content categorization

#### 📈 Key Insights
- Clear distinction between movie and TV show dominance
- Identification of popular ratings and genres
- Regional content trends and growth patterns
- Content categorization based on keywords for better understanding
